# MIDV-2020 acquisition and MRZ conversion

MIDV-2020 is not vendored in this repository. The official provider currently
states that the dataset is about **124 GB**, requires accepting its licence
through an access form, and then provides sFTP access. Downloading it into a
normal Git commit would be impractical and would violate the provider's access
and licensing workflow.

Source and access form:

- Dataset page: https://l3i-share.univ-lr.fr/MIDV2020/midv2020.html
- Access form: linked from the dataset page
- Required citation: Bulatov et al., “MIDV-2020: A Comprehensive Benchmark
  Dataset for Identity Document Analysis”, Computer Optics (2021)

After the provider gives you an sFTP endpoint, download archives outside Git:

```bash
python tools/download_midv2020.py \
  --sftp 'USER@HOST:/REMOTE/PATH/ARCHIVE.tar' \
  --out data/midv2020/raw \
  --archive-name ARCHIVE.tar \
  --identity-file ~/.ssh/id_ed25519 \
  --extract
```

If the provider gives an HTTPS mirror instead:

```bash
python tools/download_midv2020.py \
  --url 'https://example.invalid/ARCHIVE.tar' \
  --out data/midv2020/raw \
  --archive-name ARCHIVE.tar \
  --extract
```

The downloader supports restartable HTTP transfers, SHA-256 verification, sFTP,
and path-safe tar extraction. Raw archives and generated data are ignored by
Git. Once the MIDV directory is available locally, create detector labels:

```bash
python tools/prepare_midv.py \
  --root data/midv2020/raw/MIDV2020 \
  --out data/midv2020/yolo \
  --limit 100
```

The converter selects the four passport templates that contain
`mrz_line0`/`mrz_line1`, merges the two line boxes, and emits one normalized
YOLO MRZ label per image. Check the provider licence before any commercial use.
