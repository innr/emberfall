# MIDV-2020 acquisition and MRZ conversion

MIDV-2020 is not vendored in this repository. The official provider currently
states that the dataset is about **124 GB**, requires accepting its licence
through an access form, and then provides sFTP access. Downloading it into a
normal Git commit would be impractical and would bypass the provider's access
and licensing workflow.

Source and access form:

- Dataset page: https://l3i-share.univ-lr.fr/MIDV2020/midv2020.html
- Access form: linked from the dataset page
- Required citation: Bulatov et al., “MIDV-2020: A Comprehensive Benchmark
  Dataset for Identity Document Analysis”, Computer Optics (2021)

After the provider gives you an sFTP endpoint, keep each archive in its own
subdirectory so that the `images/` and `annotations/` trees do not collide:

```bash
python tools/download_midv2020.py \
  --sftp 'USER@HOST:/REMOTE/PATH/photo.tar' \
  --out data/midv2020/raw/photo \
  --archive-name photo.tar \
  --identity-file ~/.ssh/id_ed25519 \
  --extract

python tools/download_midv2020.py \
  --sftp 'USER@HOST:/REMOTE/PATH/templates.tar' \
  --out data/midv2020/raw/templates \
  --archive-name templates.tar \
  --identity-file ~/.ssh/id_ed25519 \
  --extract
```

For an HTTPS mirror, replace `--sftp ...` with `--url 'https://.../photo.tar'`
and omit `--identity-file`. The downloader supports restartable HTTP transfers,
SHA-256 verification, sFTP, and path-safe tar extraction.

The converter expects this archive layout:

```text
data/midv2020/raw/
├── photo/{images,annotations}/
└── templates/{images,annotations}/
```

Create detector labels from photographs (or use `scan_upright`, `scan_rotated`,
or `templates` for another available mode):

```bash
python tools/prepare_midv.py \
  --root data/midv2020/raw \
  --mode photo \
  --out data/midv2020/yolo \
  --limit 100
```

MIDV template annotations store `mrz_line0`/`mrz_line1` in template
coordinates. For photos and scans, the converter reads each image's `doc_quad`
and maps the merged MRZ box through a projective homography before emitting a
normalized YOLO label. Check the provider licence before any commercial use.
